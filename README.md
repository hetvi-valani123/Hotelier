# Hotelier - Hotel Website Template

Hotelier is a responsive hotel website template designed to provide a modern and attractive online hotel interface.

## Features

- Responsive hotel website design
- Simple and attractive home page
- Hotel/website information
- About section
- Services section
- Rooms section
- Booking page UI
- Contact section
- Header with navigation menu
- Footer with contact and social media information
- Responsive layout for different screen sizes
- Bootstrap-based frontend design
- Attractive hotel images and visual sections

## Pages

- Home
- About
- Services
- Rooms
- Booking
- Contact
- Login UI

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Font Awesome
- SCSS

## Project Type

This is a **frontend website template/design project**.

It does not include:

- Database
- Backend processing
- User data storage
- Real-time booking system
- Payment integration
- Authentication/database-based login

The booking page is currently a **UI/design interface only**. Submitted booking information is not stored.

## Purpose

The purpose of this project is to demonstrate the design and frontend development of a hotel website, including its navigation, hotel information, services, rooms, booking interface, and contact sections.
